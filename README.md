# 🌐 Landing Page - Moon Bandages

Una landing page desarrollada como proyecto frontend para demostrar habilidades en desarrollo web, diseño responsivo y creación de interfaces modernas.

🔗 **Demo:** https://mdsmaldonado-maker.github.io/paginanueva/

---

## 📌 Descripción

Este proyecto presenta una empresa ficticia dedicada a la venta de vendas provenientes de la Luna, con un enfoque creativo para demostrar la capacidad de desarrollar interfaces atractivas, responsivas y orientadas a la experiencia del usuario.

El objetivo principal fue aplicar buenas prácticas de maquetación, organización del código y diseño visual utilizando tecnologías web estándar.

---

## 🚀 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (ES6)
- Git
- GitHub
- GitHub Pages

---

## ✨ Características

- Diseño moderno y atractivo.

- Código organizado y fácil de mantener.
- Despliegue mediante GitHub Pages.

## 💻 Ejecución local

1. Clonar el repositorio.

```bash
git clone https://github.com/mdsmaldonado-maker/paginanueva.git
```

2. Entrar al proyecto.

```bash
cd paginanueva
```

3. Abrir `index.html` en el navegador o utilizar una extensión como **Live Server** en Visual Studio Code.
